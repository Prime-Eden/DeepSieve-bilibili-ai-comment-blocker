# DeepSieve

> **B 站 AI 评论无感滤除器** —— 接口拦截 + 判定前置 + 评分兜底，三层深筛；宁可滥杀，不可放过。

**DeepSieve** = 深筛。出生于 DeepSeek 大肥鱼战场，但目标不止于此：**无论哪家 AI 的水军，筛了再说**。

## 🙏 首先，致敬两个开源项目

**这个扩展不是凭空造出来的，它站在两个 MIT 开源项目的肩膀上**——识别引擎和拦截思路都来自它们，本项目做的是融合、去娱乐化与工程化重设计：

- **[dafeiyu-cleaner](https://github.com/liyupi/dafeiyu-cleaner)**（by [@liyupi](https://github.com/liyupi)，MIT）
  评分制识别引擎、头像鲸鱼蓝分析、跨页面前科、shadow DOM 集成——全部继承自该项目。没有这个引擎，就没有"识别"这回事。
- **[bilibili-dafeiyu-blocker](https://github.com/ybyz2/bilibili-dafeiyu-blocker)**（MIT）
  fetch/XHR 接口拦截结构、rcount 修正、置顶豁免——"评论在渲染前就被删掉"的零闪烁体验，思路来自这个脚本。

详细的技术差异与取舍见文末[「与参考项目的区别」](#与参考项目的区别)。

## 它解决什么问题

B 站评论区正在被 AI 水军淹没：DeepSeek 驱动的"大肥鱼"小号自称本鲸、@ 主人汇报；其他家模型的马甲号写着工整的小作文、批量灌水。现有方案各有遗憾——

- 有的插件能识别，但**鲸鱼娘贴标 + 动画 + 音效 + 战报**，热闹得像过年；
- 有的脚本删得干脆，但**只认关键词**，删了就删了，误杀了你根本不知道；
- 几乎所有方案都有同一个尴尬：**评论先渲染出来再被撤下——屏幕上闪一下**。

**DeepSieve** 的答案是：**三层过滤 + 无感哲学 + 可审计 + 会学习**。

- **无感**：判定命中的评论直接消失。没有动画、没有贴图、没有声音，你在页面上能看到的，只有一行可关闭的「已清 N 条」和圆钮上的一枚角标；
- **可疑可见**：像但没实锤的账号不隐藏，只在昵称旁挂一枚「可疑 N%」小徽标，悬停看完整判定依据——判断权还在你手里；
- **可审计**：每一条被隐藏的评论都有记录（谁、说了什么、为什么、被哪层拦下），一键恢复，永不黑箱；
- **会学习**：你手动拉黑的每一次裁决都会沉淀成特征计数，让同类账号更快过线——**不管它来自哪家模型**。

## 功能总览

| 功能 | 说明 | 在哪设置 / 操作 |
|---|---|---|
| 无感隐藏 | 评分 ≥ 阈值的账号，评论直接消失 | 识别页（阈值滑杆 45–80） |
| 三层过滤 | 接口拦截 + 判定前置 + 评分兜底，老鱼零闪烁 | 自动，无需配置 |
| 楼中楼策略 | 只隐藏该账号 / 整楼隐藏 / 不管楼中楼 | 识别页 |
| 自定义屏蔽词 | ≤100 个，命中即无条件下，接口层直接拦截 | 屏蔽词页 |
| 疑似徽标 | 可疑账号不隐藏，昵称旁挂「可疑 N%」，悬停看依据 | 自动；DeepSeek 精判后加 DS 角标 |
| 徽标一键清理 | 可疑徽标右侧「清理」按钮，一键拉黑 | 页面内 |
| 框选屏蔽 | 拖矩形，框内账号全拉黑 | 清扫台 → 框选屏蔽 |
| 灵敏度三档 | 宽松 70 / 标准 60 / 严格 50，一键切换 | 清扫台 |
| 人工强化回路 | 手动拉黑沉淀特征计数，同类账号更快过线 | 自动；清扫台「人工强化」行显示进度 |
| 两级审计 | 本页记录（会话）+ 隐藏总记录（持久 2000 条），可恢复可导出 | 名单页 |
| 白名单 | 误杀一键恢复 = 加白名单，永久放行 | 名单页 / 记录行「恢复」 |
| DeepSeek 精判（可选） | 拿不准的账号二次判定，55% 权重并入终分 | DeepSeek 页 |
| 清扫台 | 可拖动悬浮操作台，只在视频页出现 | 识别页开关 |
| 已清计数条 | 接口层 + 页面层合并计数，切视频归零 | 识别页开关 |
| 纯 @ 召唤识别 | 全部（≥3 条）直接判鱼，大部分（≥60%）加权进可疑带——无视人类减分 | 自动 |

## 使用指南

### 安装

1. 下载 Release 里的 `DeepSieve-bilibili-ai-comment-blocker-vX.Y.Z.zip` 并解压
2. `edge://extensions`（Chrome 是 `chrome://extensions`）→ 开启「开发人员模式」
3. 「加载解压缩的扩展」→ 选择解压出的文件夹（含 `manifest.json` 的一层）

装完打开任意 B 站视频，滚到评论区即自动开始工作。

### 设置面板

点工具栏扩展图标打开，四个标签页：

- **识别**：总开关、判定阈值（默认 60%，低于阈值不隐藏只算可疑）、楼中楼三策略、已清计数条开关、悬浮控制台开关、前科记忆
- **屏蔽词**：自定义屏蔽词（≤100 个），评论命中任意一个词 → 该账号直接隐藏，接口层同步拦截
- **DeepSeek**：可选精判（自带 API Key），离线规则拿不准的可疑账号二次判定，55% 权重并入终分
- **名单**：屏蔽名单（搜索 / 导出 / 导入 / 清空）、本页记录（逐条恢复）、隐藏总记录（导出 / 清空）、导入历史

### 清扫台（悬浮操作台）

识别页打开「悬浮控制台」后，视频页右下角出现 42px 扫帚圆钮：

- **拖动**：按住拖到任意位置，松手记忆（换分辨率也落回相对位置）；悬停圆钮出现 × 可直接收起
- **点开**：
  - 顶部：已清数字 + 扫描账号数 + 四档分数分布（人类 / 低疑 / 可疑 / 判鱼）
  - 主操作：**清扫本页**（已判定的全部隐藏）、**框选屏蔽**（拖矩形拉黑漏网之鱼）
  - **灵敏度**：宽松 70 / 标准 60 / 严格 50，点一下全局切换阈值
  - **人工强化**：裁决次数 + 已掌握特征——你的每次裁决都会让它长大
  - **最近隐藏**：最近 3 条，行内「恢复」一键放行；「全部记录 ↗」直达设置页
  - 工具行：重扫 / 计数条开关 / 暂停屏蔽 / 设置 / 收起悬浮台

点任何功能都**不会**关闭菜单；只有框选、设置、全部记录、收起才离开。

### 三种裁决方式

1. **自动**：评分 ≥ 阈值 → 隐藏 + 进名单（默认，无感）
2. **半自动**：可疑徽标（像但没实锤）→ 不隐藏，看着不顺眼就点徽标上的「清理」
3. **手动兜底**：框选屏蔽——引擎漏网的鱼，拖个框全收

三种方式都走同一条管线：隐藏 + 计数 + 记录 + 进名单（此后接口层永久拦截，零闪烁）。

### 恢复误杀

- popup → 名单页 → **本页记录**：逐条「恢复」（= 加白名单，永久放行；接口层拦掉的刷新页面后重现）
- 名单页 → 屏蔽名单：搜索后「移除」
- 每条记录含全文、评分、发言特征、来源、时间——误杀审计不黑箱

### 导入导出

- 名单页「导出」：屏蔽名单 + 白名单 JSON（兼容原版 dafeiyu-cleaner 格式）
- 隐藏总记录「导出全部」：含全文 / 评分 / 发言特征 / 来源 / 时间的完整档案
- 两个「导入」都会自动识别文件类型并合并去重，结果有提示条反馈

## 三层过滤（怎么做到零闪烁）

| 层 | 时机 | 管谁 |
|---|---|---|
| **接口层** | 渲染前 | 屏蔽名单账号、屏蔽词命中的评论，在 fetch/XHR 响应数据里直接删除 |
| **判定前置** | 渲染前 | 接口数据先送识别引擎同步打分，已判鱼的账号在元素挂载回调里（绘制前）隐藏 |
| **评分兜底** | 渲染后 | 需要页面上下文（头像色 / 楼中楼点名 / UP 主身份）的新鱼，首帧后定案并进名单 |

规则快照存 localStorage：新页面一打开，拦截层就带着全量名单上岗。**老鱼零闪烁，新鱼一次闪，此后永久消失。**

## 识别引擎怎么打分

离线、本地、可解释。每个账号 0–99 分：

- 昵称 / 签名规则（本鲸系命名、AI 代管人设、DS / 白饭 / bot…）
- 等级警惕：Lv≤2 +14、Lv3 +8、Lv4 +5（低等级 ≈ 刚注册，小号高发区）；Lv6 老号 −10
- 近期注册号段（mid ≥ 3e9）且低等级：+8
- **头像鲸鱼蓝占比**：canvas 分析，AI 头像普遍大面积蓝
- 默认头像、多账号同秒发评：小号指纹，低权重
- 文本 19 条规则：自称本鲸、括号演鲸鱼、@ 主人汇报、Markdown 残留、AI 总结腔、数弹幕 ×19…
- 行为：本页刷多条、每条一个味儿；楼中楼被真人点名；**跨页面前科**
- **人工确认特征**：你手动拉黑确认 ≥3 次的特征，判定加权（封顶防过拟合）
- UP 主本人、官方认证、大会员、白名单：减分 / 豁免

达到阈值隐藏；阈值−25 以上算「可疑」，不隐藏只标注。AI 话题视频下，账号证据加权、话题可解释的文本规则减权——真人聊 AI 不误伤。

## 隐私与红线

- 设置、名单、前科记忆、隐藏记录全部只存本机
- **不调用 B 站任何写接口（不删评 / 不举报 / 不拉黑站方），不读 Cookie，无统计上报**
- 仅开启 DeepSeek 精判后，可疑账号的昵称 / 等级 / 签名 / 最多 3 条评论会发送到 `api.deepseek.com`（你自己的 Key）
- 详见 [PRIVACY.md](PRIVACY.md)

## 兼容性

Chrome / Edge 105+（Manifest V3），适配 B 站新版评论区（bili-comments Web Components）。暂不支持弹幕过滤。

## 与参考项目的区别

本项目是两个 MIT 开源项目的思路与代码的融合重设计，感谢原作者：

- **识别引擎与架构基座**：[liyupi/dafeiyu-cleaner](https://github.com/liyupi/dafeiyu-cleaner)（MIT）——评分制引擎、头像鲸鱼蓝分析、shadow DOM 集成、跨页面前科完整继承；本项目去除了其全部娱乐演出（鲸鱼娘 / 武器 / 音效 / 战报），重写了隐藏管线、清扫台与设置面板
- **接口拦截思路**：[ybyz2/bilibili-dafeiyu-blocker](https://github.com/ybyz2/bilibili-dafeiyu-blocker)（MIT）——fetch/XHR hook 结构、rcount 修正、置顶豁免、首屏判定借鉴自该项目；本项目在其关键词拦截之上叠加了评分引擎、判定前置与自学习

简单说：**识别的深度来自 cleaner，无感的果断来自 blocker，自学习与可审计是本项目新增**。
