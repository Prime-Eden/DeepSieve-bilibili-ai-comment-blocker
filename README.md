# DeepSieve

过滤 B 站评论区里的 AI 评论和机器人账号。识别为 AI 的账号，评论直接隐藏。

名字来自 DeepSeek 被大量拿来做评论机器人的那阵子，但识别不限于哪一家的模型。

## 致谢

识别引擎和拦截思路都来自两个 MIT 开源项目，这个扩展是在它们的基础上改的：

- [dafeiyu-cleaner](https://github.com/liyupi/dafeiyu-cleaner)（[@liyupi](https://github.com/liyupi)）：评分制识别引擎、头像颜色分析、跨页面记忆、shadow DOM 集成都来自这里。本项目去掉了它的娱乐效果，重写了隐藏流程、悬浮台和设置面板。
- [bilibili-dafeiyu-blocker](https://github.com/ybyz2/bilibili-dafeiyu-blocker)：fetch/XHR 拦截的结构、楼中楼计数修正、置顶评论豁免来自这里。本项目在它的关键词拦截上加了评分引擎。

## 安装

1. 下载 Release 里的 zip，解压。
2. 打开 `chrome://extensions`（Edge 是 `edge://extensions`），打开「开发者模式」。
3. 点「加载已解压的扩展程序」，选择解压出来、里面有 `manifest.json` 的那个文件夹。

装好后打开任意 B 站视频，滚到评论区就会开始工作。

## 功能

- 隐藏：账号的嫌疑分达到门槛就隐藏它的评论，不带动画和提示。
- 可疑标记：嫌疑分不够隐藏、但比较可疑的账号，昵称旁会挂一个「可疑 N%」，鼠标放上去能看依据。
- 悬停拉黑：鼠标在评论上停留，出现「拉黑」按钮，点完 3 秒内可以撤销。纯 @ 的账号（发的评论全是 @）直接隐藏。
- 框选屏蔽：在悬浮台里拖一个框，框里的账号一起拉黑。
- 屏蔽词：评论里包含其中任意一个词，就隐藏该账号的评论，最多 500 个。
- 保留长评论：超过 60 字、看不出明显 AI 腔的评论不隐藏，可以关掉。
- 楼中楼：可以选只隐藏该账号、整楼隐藏，或者不处理楼中楼。
- 名单和记录：可以看到屏蔽了哪些账号、本页隐藏了哪些评论，误杀的可以恢复。
- DeepSeek 精判（可选）：用自己的 API Key，让 DeepSeek 再判断一次拿不准的账号。
- 悬浮台和计数条：可以在设置里打开，不开也不影响使用。

## 空间主页鉴定

点进别人的空间页时，右上角会出现一张小卡片：嫌疑分、判定依据、屏蔽和放行按钮。同样的规则，只是换个地方看。

## 设置面板

点工具栏里的扩展图标。

- 识别：总开关、识别灵敏度、悬停拉黑按钮、楼中楼处理、保留长评论。
- 屏蔽词：添加、导入、导出。
- DeepSeek：填 API Key，开启精判。
- 名单：已屏蔽账号、放行账号、本页和历史的隐藏记录，可以导入导出。

识别灵敏度越往「严格」，嫌疑分的门槛越低，更容易隐藏，误隐藏也会多一些。悬浮台里有宽松、标准、严格三档，分别对应门槛 70%、60%、50%。

## 隐藏是怎么做到不闪的

分三步：

1. 接口层：已屏蔽账号和命中屏蔽词的评论，在 fetch/XHR 返回的数据里就删掉，页面拿不到。
2. 渲染前：接口数据先交给识别引擎打分，判为 AI 的账号在元素挂载时就隐藏。
3. 渲染后：需要页面信息（头像颜色、被人点名、UP 主身份）的账号，在页面出来后再判断，判定后加入名单。

已经在名单里的账号不会闪，新发现的账号可能闪一下，之后就不会了。

## 识别引擎怎么打分

规则都在本地运行，每个账号 0 到 99 分：

- 昵称和签名里的特征词。
- 等级：低等级账号加分，高等级老号减分。
- 近期注册的低等级账号加分。
- 头像里蓝色占比高的加分。
- 评论文字里的特征，比如自称「本鲸」、@ 主人汇报、Markdown 残留、总结式的话。
- 行为：同一页发很多条、被真人点名、在别的视频里也被判过。
- 你手动拉黑过几次的特征，会让同类特征更容易过线，有次数门槛和封顶。
- 发的评论全是 @（三条以上）的账号直接隐藏，大部分是 @ 的加权。
- UP 主本人、官方认证、大会员、放行名单里的账号减分或豁免。

UP 主本人的规则：自动判定不会隐藏 UP 主，也不会把 UP 主自动加进屏蔽名单；你手动拉黑了，才会隐藏。

嫌疑分达到门槛才隐藏，比门槛低 25 分以上的只标「可疑」。AI 话题的视频里，账号特征的权重会高一些，评论内容里聊 AI 的话题词不算分。

## 隐私

- 设置、名单、记忆、隐藏记录都只存在本机。
- 不调用 B 站的写接口，不读 Cookie，没有统计上报。
- 只有开启 DeepSeek 精判后，可疑账号的昵称、等级、签名、最多 3 条评论会发到 `api.deepseek.com`，用的是你自己的 Key。

详见 [PRIVACY.md](PRIVACY.md)。

## 兼容性

Chrome / Edge 116 以上（Manifest V3），适配 B 站现在的评论区。不支持弹幕过滤。

更多细节（三层过滤的完整说明、四种裁决方式、审计与恢复、体检报告）见 [README-full.md](README-full.md)。
